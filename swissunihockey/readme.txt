=== Swissunihockey Web Components ===
Requires at least: 5.9
Tested on: 7.1
Stable tag: 1.0.0
License: GPLv2 or later


Bindet die Swissunihockey Web Components (https://github.com/swissunihockey/swissunihockey-webcomponents/tree/master) per Shortcode ein. JS/CSS werden extern (jsDelivr) geladen; URLs unter Einstellungen > Swissunihockey änderbar.

Für die Nutzung ist eine Registrierung bei Swissunihockey Pflicht. 
https://www.swissunihockey.ch/de/administration/services/webmaster/


## Nutzungsbedingungen

Bitte immer die Vorgaben von Swissunihockey beachten. Registrierung unter https://www.swissunihockey.ch/de/administration/services/webmaster/ ist obligatorisch.
Dieses Plugin kann von allen Vereinen frei genutzt werden. 
Feedbacks oder auch Pullrequest gerne via Github.
