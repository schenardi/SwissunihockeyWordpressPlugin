=== Swissunihockey Web Components ===
Requires at least: 5.9
Tested up to: 6.6
Stable tag: 1.0.0
License: GPLv2 or later

Bindet die Swissunihockey Web Components per Shortcode ein. JS/CSS werden extern (jsDelivr) geladen; URLs unter Einstellungen > Swissunihockey änderbar.
Quelle https://github.com/swissunihockey/swissunihockey-webcomponents/tree/master
Für die Nutzung ist eine Registrierung bei Swissunihockey notwendig, https://www.swissunihockey.ch/de/administration/services/webmaster/

== Shortcodes ==
* [swissunihockey_league_games game_class="21" league="3" season="2025" group="Gruppe 1"]
* [swissunihockey_club_team_games club_id="372" season="2025" page_size="6"]
* [swissunihockey_team_games team_id="429626" season="2025" page_size="5"]
* [swissunihockey_club_games club_id="467" season="2025"]
* [swissunihockey_ranking league="3" game_class="21" group="Gruppe 1" season="2025"]
* [swissunihockey_mobiliar_topscorer club_id="463845" season="2025"]

Ohne season wird die Standard-Saison verwendet.
